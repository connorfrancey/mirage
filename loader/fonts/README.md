# Fonts kept in the repository

- `JetBrainsMonoNerdFont-Regular.ttf`: JetBrains Mono (SIL Open Font License 1.1) patched by Nerd Fonts with icon
  glyphs, the script editor's font (features/misc/script_editor.cpp). Embedded in Mirage.dll as resource 901
  (cmake/Fonts.cmake), loaded by hooks.cpp. SHA-256 1c680e8cde9fcf8b88a5605ce8d1fb94dd3fb15841f7ca7bf4c55664855e5611.

The menu's other fonts come from Dear ImGui's sources and Font Awesome's release (cmake/Fonts.cmake).
