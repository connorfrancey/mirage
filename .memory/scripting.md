# Scripting and mod APIs

- Native mods receive `MirageApi` and an opaque mod handle. `mirage.hpp` wraps the C table, `sdk.hpp` adds typed engine access, and `imgui.hpp` handles compatible ImGui context use. Preserve the table layout and verify changes with the ABI test. [C API](../loader/include/mirage/api.h), [ABI test](../tests/test_abi.cpp)
- A Lua mod owns a Lua state with a memory ceiling, instruction budget, and selected standard libraries. `mod_lua.cpp` assembles its `mirage` API and local require behavior. Area bindings live in `runtime/lua/lua_*.cpp`; their function registries feed the API assembly. [Lua loader](../loader/src/runtime/mod_lua.cpp), [VM](../loader/src/runtime/lua_vm.cpp), [bindings](../loader/src/runtime/lua)
- Managed mods use a bundled x86 .NET 10 host via hostfxr. The bridge supports managed assemblies and Roslyn-compiled script mods. Match the native ABI in the managed bindings when changing calls. [Native host](../loader/src/runtime/mod_dotnet.cpp), [managed host](../managed/Mirage/Host), [C# authoring](../docs/csharp-mods.md)
- UnrealScript classes use `class_source` and `classes`; UnrealLib compiles source that the game then loads. Function hooks, script patches, injected calls, and registered natives have distinct owners. Check composition and undo ordering before combining them. [Class pipeline](../loader/src/runtime/class_source.h), [classes guide](../docs/mod-classes.md), [hooks](../loader/src/runtime/fhooks.h), [injection](../loader/src/runtime/inject.h), [patches](../loader/src/runtime/script_patch.h), [natives](../loader/src/runtime/natives.h)

Use the [API reference](../docs/api-reference.md) and [authoring guide](../docs/mod-authoring-ai.md) for syntax and examples. Use [engine integration](unreal-engine.md) when tracing a wrapper into UE3.
