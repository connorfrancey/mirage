# Development tools

| Workflow | Entry point |
| --- | --- |
| Build, configure, verify, install the loader | `tools/mirage_tools/cli.py` dispatches to the build, toolchain, and game-test helpers. [CLI](../tools/mirage_tools/cli.py), [build](build.md) |
| Create, check, build, package, install, or test a mod | `mirage new` and `mirage mod` use `modtools.py` and language or data templates. Offline checks cover the authoring layout; runtime TOML parsing remains authoritative. [Author tools](../tools/mirage_tools/modtools.py), [templates](../tools/mirage_tools/templates) |
| Browse engine types or find object paths | `mirage sdk`, `sdk-browse TdPawn` (`-i` inherited, `-f` functions, `-m` member lookup), and `index` route to generated layouts and catalog tools. `sdk-browse --gui` opens the PyQt6 browser. [CLI](../tools/mirage_tools/cli.py), [SDK tool build](../tools/sdkgen/CMakeLists.txt) |
| Browse game assets | `mirage assets [query]` opens game asset results and accepts `--rebuild` to refresh the catalog. Check feature and checkout availability. [CLI](../tools/mirage_tools/cli.py) |
| Inspect or convert a model | `mirage model` uses the separate Assimp-based model tool. [Model tool](../tools/model/CMakeLists.txt), [authoring](../docs/models.md) |
| Generate API references and documentation | `mirage docs api`, the API generator, and CMake docs targets. Read the docs build guide for dependencies and the docs-only configuration. [API generator](../tools/mirage_apigen), [docs guide](../docs/documentation/README.md) |

`uv run mirage` is installed from the Python project entry point. The repository's file map, generated by `python tools/file_map.py`, is a broader navigation reference. [Python metadata](../pyproject.toml), [file map](../docs/FILE-MAP.md)
