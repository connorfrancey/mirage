# Mirage Documentation

Mirage loads native, Lua, and C# mods into the 32-bit PC build of Mirror’s Edge.

- [Getting started](getting-started.md) builds and installs your first mod.
- [Architecture](infrastructure.md) explains how the loader dispatches work and handles errors.
- [C++ API](documentation/cpp.md) covers the native ABI and loader interfaces.
- [Lua API](documentation/lua.md) covers the script environment and callbacks.
- [SDK](documentation/sdk.md) covers generated UE3 types and metadata export.
- [Mod authoring guide for coding agents](mod-authoring-ai.md) walks through Lua, content, and multi-file mods.
- [Contributing](documentation/README.md) explains how to build and maintain this documentation.
